# Sistema Integrado de Segurança

## Descrição

Sistema desenvolvido em Python com interface gráfica em Tkinter para gestão de utilizadores e controlo de acessos, utilizando SQLite para armazenamento dos dados.

## Funcionalidades

- Login de utilizadores
- Registo de utilizadores
- Controlo de acessos
- Gestão de permissões
- Registo de logs

## Tecnologias

- Python
- Tkinter
- SQLite

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/arthrtx/Sistema-de-Seguran-a.git
```

2. Entre na pasta do projeto:

```bash
cd Sistema-de-Seguran-a
```

3. Execute a aplicação:

```bash
python login.py
```
